# .github
README
Any staff member or authorized contributor from an EUPeace partner institution may request membership in the EUPeace GitHub Organization. Membership is approved by the EUPeace GitHub administrators. External contributors may either be admitted as members where repository creation is required or added as outside collaborators to individual repositories. To become a member of the Organisation apply with name, email adress, institution, GitHub username via admin@eupeace.eu.
